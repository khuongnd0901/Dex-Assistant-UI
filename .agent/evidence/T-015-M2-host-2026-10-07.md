# T-015 M2 — semantic resolver host slice (2026-10-07)

## Implemented

- Android adds a bounded, local `SemanticUiResolver` using the existing
  `TypedAction`/`ActionRouter` path. The caller must name a configured app;
  `DesktopUiAccess` reads only the selected Samsung DeX application window.
  Selectors use exact resource ID/text/description, role and card-local context;
  ordinal is applied after filtering. Ambiguous results use the existing spoken
  choice/confirmation path. No UI tree, image or audio is sent to the backend.
- `DesktopUiAccess` requires candidate bounds inside the selected window and
  re-reads display/window/topology/node identity before its one scoped gesture.
  The result remains `DISPATCHED`, not proof that media played.
- YouTube card labels now include artist metadata when present. Results with
  the same normalized title are rejected before choice/gesture unless every
  card has nonblank, distinct artist/context. This applies to play-query and
  title/index selection; unrelated duplicate groups do not block a unique
  requested title.
- Runtime still advertises schema 1 and excludes `CLICK_TARGET` from
  `supportedActions()`. Schema 2 is withheld pending physical Fold3 acceptance.
