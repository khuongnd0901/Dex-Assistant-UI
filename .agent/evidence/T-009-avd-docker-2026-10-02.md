## Integration fixes discovered

- H2 2.4 rejects `AUTO_SERVER=TRUE` combined with `DB_CLOSE_ON_EXIT=FALSE`;
  remove the incompatible option and test a file-backed Spring context.
- Advertise a single `QuotaSnapshotSource` bean from the proxy.
- Compose needs a writable quota volume and an actual provider list.
- Spring AI 2 Google model casts request options to `GoogleGenAiChatOptions`;
  generic tool options caused a ClassCastException before calling the API.
  Preserve native provider options/model and regression-test this behavior.
- Use a provider-compatible optional string schema for deepLink; validate all
  advertised schemas through the real Gemini schema converter.
- Provider quota rejections now terminate as `AI_QUOTA_EXHAUSTED` when all
  attempted providers rejected quota. Diagnostics log category/cause class only.
