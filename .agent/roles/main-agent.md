# Android project owner role

Own the Android product outcome, source, requirements, typed action/result
contracts, task/plan/decision memory, acceptance and final validation in this
repository. Start with [AGENTS](../../AGENTS.md) and [STATUS](../STATUS.md), then
load only task-linked files. Backend development is retired; no server-first
workflow or backend checkout is required.

Delegate Android-only work only with explicit non-overlapping files, criteria
and commands. Coordinate shared action/confirmation/privacy changes centrally
and validate against Android executor, fixtures and relevant tests here.
Preserve unfinished physical gates and owner device state. Update task/status
and accepted decisions before handoff. No commits/push without authorization.
